# Анализ донорской активности

## Проект
Анализ данных о донорах, их активности, вовлеченности через социальные сети, влиянии бонусов и выполнении планов донаций.

## Инструменты
- **SQL** (PostgreSQL)

## Задачи и результаты

### 1. Регионы с наибольшим количеством доноров
- Москва, Санкт-Петербург, Казань, Киев — лидеры
- 100 574 донаций без указания региона

### 2. Динамика донаций по месяцам (2022–2023)
- Пик активности: март, апрель
- Спад: май–июнь, конец 2023 года

### 3. Наиболее активные доноры
- Лидер: ID 235391 (361 донация)

### 4. Влияние бонусов
| Статус | Доноров | Среднее донаций |
|--------|---------|-----------------|
| Получили бонусы | 21 108 | 13.90 |
| Не получали | 256 491 | 0.53 |

### 5. Вовлечение через соцсети
- Яндекс и Telegram — самая высокая активность
- ВКонтакте — самый массовый канал

### 6. Активность повторных доноров
- Обнаружены аномалии в данных (даты до 1800 лет)
- Требуется очистка данных

### 7. Планирование vs реальные донации
| Тип | Выполнение |
|-----|------------|
| Безвозмездно | 21.61% |
| Платно | 13.00% |

## Рекомендации

- Усилить маркетинг в Яндекс и Telegram
