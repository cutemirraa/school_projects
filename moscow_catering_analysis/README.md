# Анализ рынка общественного питания Москвы (лето 2022)

## Описание проекта
Исследовательский анализ данных о заведениях общественного питания Москвы на основе информации сервисов Яндекс Карты и Яндекс Бизнес (лето 2022 года). Цель — выявить перспективные районы и форматы для открытия нового заведения.

## Данные
- `rest_info.csv` — информация о заведениях (название, адрес, район, категория, часы работы, рейтинг, сетевое/несетевое, количество посадочных мест)
- `rest_price.csv` — информация о ценах (категория цен, средний чек, цена чашки кофе)

Исходное количество заведений: 8 406. После предобработки: 7 867.

## Основные выводы

### Категории заведений
В Москве представлено 8 категорий. Лидеры по количеству: «кафе» (2 002) и «ресторан» (1 967). Реже всего встречаются столовые (306) и булочные (249).

### Административные районы
Больше всего заведений — в Центральном округе (2 211), меньше всего — в Северо-Западном (369). В центре преобладают рестораны (665), в остальных районах — кафе.

### Сетевые и несетевые заведения
Доля сетевых заведений — 39.3%, несетевых — 60.7%. Самая высокая доля сетевых у булочных (62%), пиццерий (53%) и кофеен (51%).

### Посадочные места (медиана)
| Категория | Мест |
|-----------|------|
| ресторан | 86 |
| бар, паб | 82 |
| кофейня | 80 |
| столовая | 74 |
| быстрое питание | 70 |
| кафе | 60 |
| пиццерия | 55 |
| булочная | 50 |

### Рейтинг заведений
Все категории имеют высокие рейтинги (от 4.06 до 4.39). Самый высокий средний рейтинг — у баров и пабов (4.39), самый низкий — у быстрого питания (4.06).

### Корреляция с рейтингом
- Средний чек умеренно коррелирует с рейтингом (коэффициент Спирмена: 0.36)
- Ценовая категория показывает слабую связь (коэффициент phi_k: 0.22)

### Топ-15 сетей
- Крупнейшая сеть — «Шоколадница» (120 точек, кофейня, рейтинг 4.18)
- Самый высокий рейтинг среди топ-15 — у «Буханки» (4.40, булочная)
- Самый низкий — у «Яндекс Лавки» (3.87)

### Средний чек по районам
- Самый высокий — в ЦАО (1 190 руб.)
- Самый низкий — в ЮВАО (654 руб.), СВАО (716 руб.), ЮЗАО (792 руб.)
- Закономерность: чем дальше от центра, тем ниже средний чек

## Рекомендации

1. **Район:** Для высокого чека — ЦАО (но высокая аренда). Для меньшей конкуренции — ЮВАО, СВАО или ЮЗАО (но чек ниже).
2. **Формат:** Кофейня или пиццерия (высокая доля сетевых + высокий рейтинг).
3. **Цены:** 800–1 000 руб. средний чек — баланс между центром и спальными районами.
4. **Посадочные места:** Для кофейни/кафе — 60–80 мест, для ресторана — 85–100.
