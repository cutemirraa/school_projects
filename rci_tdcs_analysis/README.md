# tDCS for Allergic Rhinitis: Statistical Analysis 

## Project Description
This project presents a complete statistical analysis of a fictional Randomized Clinical Trial (RCT) evaluating the efficacy of transcranial direct current stimulation (tDCS) for the treatment of allergic rhinitis. The dataset was synthetically generated for portfolio purposes only.

## Key Findings
- **Relative Risk (RR) = 2.59** (95% CI: 1.87–3.59) — tDCS is 2.6 times more effective than placebo
- **NNT = 4.0** — only 4 patients need treatment for one additional positive outcome
- Symptom scores decreased by 46.7% immediately after tDCS and remained 28.0% lower at day 7
- No significant improvement in the Sham group (max reduction: 4.5%)

## Tools Used
- Python (pandas, numpy, matplotlib, seaborn)
- Statistical tests (Mann–Whitney U, t-tests, RR with 95% CI)
- Visualizations (boxplots, pairplot, heatmap, forest plot)

## Project Structure
- `Part 0`: Environment setup
- `Part 1`: Data overview & preprocessing
- `Part 2`: Exploratory Data Analysis (EDA)
- `Part 3`: Statistical tests (RR, CI, NNT, forest plot)
- `Part 4`: Conclusions & recommendations

## Data
The dataset `RCT_tDCS_Allergic_Rhinitist.csv` contains:
- 500 patients, 250 per group (tDCS / Sham)
- Biomarkers: IL-6, TNF-Alpha, IgE
- Symptom scores at 4 time points
- Binary outcome: Response (0/1)

This dataset and clinical trial are **entirely fictional**. Created for portfolio demonstration only.
