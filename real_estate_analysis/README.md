# Анализ рынка недвижимости Санкт-Петербурга и Ленинградской области

## Проект
Анализ данных объявлений о продаже жилой недвижимости (Яндекс Недвижимость) для агентства из Петрозаводска, планирующего выход на рынок СПб и ЛО.

## Инструменты
- **SQL** (PostgreSQL) — выгрузка, фильтрация выбросов, агрегация данных
- **Yandex DataLens** — дашборд с визуализациями

## Задачи

### Задача 1. Время активности объявлений
Определены категории объявлений по длительности размещения (1-30, 31-90, 91-180, 180+ дней, non category).  
Проанализирована связь скорости продажи с характеристиками недвижимости.

**Результаты:**
- В СПб самая популярная категория — **180+ дней** (3 506 объявлений)
- В Ленобласти лидируют категории **31-90 дней** (864) и **180+ дней** (873)
- Низкая цена за кв.м ускоряет продажу в СПб (108 920 руб. — продажа за месяц, 136 108 руб. — не проданы)
- В Ленобласти зависимость цена/скорость выражена слабее

### Задача 2. Сезонность объявлений
Проанализирована активность публикаций и снятий объявлений по месяцам.

**Результаты:**
- Пик публикаций: **февраль (1246)** и **ноябрь (1181)**
- Пик снятий (продаж): **октябрь (1360)** и **ноябрь (1301)**
- К концу года продажи превышают публикации
- Цена за кв.м растет к сентябрю, затем снижается

## Общие выводы и рекомендации
- Оптимальное время для выхода на рынок — **конец лета / начало осени**
- Наиболее выгодно продавать **осенью** (высокая цена + высокая активность покупателей)
