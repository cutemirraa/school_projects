# Venture Capital Funding Analysis (Startups 2000–2014)

## Описание проекта
Анализ венчурного финансирования стартапов за 2000–2014 годы. Исследование структуры финансирования, классификация сегментов рынка, сравнение типов финансирования, анализ динамики возвратов и формирование рекомендаций по инвестиционной стратегии на 2015 год.

## Ключевые выводы
- 58.9% компаний имеют только один раунд финансирования, но получают лишь 30.6% всех денег
- 30.1% компаний с длительным циклом (>1 года) привлекают 61.9% всех инвестиций
- `venture` — лидер по объёму инвестиций (129 млрд), популярности (18 820 компаний) и возвратам (40.6 млрд)
- Сегмент `medical` показал наиболее уверенный рост к 2014 году
- Данные за 2014 год неполные (спад в ноябре–декабре)

## Рекомендации на 2015 год
- **Куда инвестировать:** сегмент `medical`
- **Тип финансирования:** `venture`

## Инструменты
- Python (pandas, matplotlib)
- Jupyter Notebook
- Анализ выбросов методом IQR
